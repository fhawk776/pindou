## 一、第一次使用

### 手机上添加桌面图标（推荐）

1. 手机浏览器（**不要用微信**）打开上面的地址
2. 输入账号密码登录
3. 安卓：菜单 →「添加到主屏幕」；iPhone：分享 →「添加到主屏幕」
4. 以后点桌面图标就能直接打开，不用记地址

### 立即修改密码

底部「**我的**」→「**修改密码**」

新密码要求：至少 10 位，含**大写字母 + 小写字母 + 数字**（例：`Pindou2026Shop`）

## 二、日常操作

### 1. 顾客进店 → 开台

```
底部「店铺」 → 点空闲的桌位（显示「点击接待顾客」）
    ↓
选择顾客身份：
   · 老会员 → 搜索昵称或手机尾号 → 点选
   · 新顾客 → 点「＋ 新会员开卡」先建档
   · 散客   → 输入一个称呼（如「穿蓝衣服的姐姐」）
    ↓
选套餐 → 弹出「确认开台」→ 点确认
```

**开台后立即开始计时。**

### 2. 顾客中途离开 → 暂停计时

```
点该桌进入详情 → 点「暂停计时」
    ↓
顾客回来 → 点「恢复计时」
```

**暂停期间不计费。** 暂停中看板会显示黄色「⏸ 已暂停」徽章。

> 例：14:00 开台（1小时套餐），14:30 暂停，15:00 恢复
> → 只算 30 分钟 + 恢复后的时长，中间半小时不收钱

### 3. 顾客要加东西 → 加购

```
详情页「加购」区 → 用 − / + 调数量
```

可加：智能拼豆板（¥9.90/个）、特殊烫（¥2.88/个）

**金额实时显示在下方。**

### 4. 套餐选错了 / 想升级 → 换套餐

```
详情页「换套餐」→ 点新套餐 → 确认
```

限时套餐（1小时/3小时）、限板套餐（52/78/104钉）、日卡**之间都能互换**。

> ⚠️ 换成限时套餐会按新时长重算剩余时间；换成限板/日卡则变为不限时。

### 5. 顾客要走 → 结账

```
详情页点「确认结账」
    ↓
弹出账单核对单，逐项显示：
   桌位、顾客、套餐、加购、超时时长、打折优惠
    ↓
【实收金额】默认等于应收，可手动改
   · 熟人少收 → 直接填少的金额，下方显示「少收 ¥X」
   · 顾客给整钱不用找零 → 填多的金额，显示「多收 ¥X」
    ↓
选【支付方式】：微信 / 支付宝 / 现金 / 卡核销 / 其他
    ↓
点「确认收款 ¥XX」
```

**结账后桌位自动释放。**

### 6. 办卡 / 续卡 / 退卡

**办卡有两个入口，效果完全一样**：

```
入口一（推荐，最快）：开台页 → 选好顾客 → 点「🎫 卡权益」里的周卡
                      → 确认「办卡并开台」→ 收钱、办卡、开台一次完成

入口二：底部「会员」→ 点会员 → 会员详情 →「办卡」
        办完回到开台页，点绿色「用卡开台」
```

| 操作 | 位置 | 说明 |
|---|---|---|
| **办卡并开台** | 开台页 → 🎫 卡权益 | 办卡 + 立刻开台，一步到位（推荐） |
| **只办卡** | 会员详情 →「办卡」 | 顾客先办卡、下次再来 |
| **用卡开台** | 开台页 → 绿色「用卡开台」 | 已持卡时用，全天不限时、不计超时 |
| **续卡** | 会员详情 →「续卡」 | 新一期紧接原到期日之后 |
| **冻结** | 会员详情 → 权益管理 →「冻结」 | 有纠纷时先停用权益 |
| **退卡** | 会员详情 → 权益管理 →「退卡」 | 手动填退款金额 |

#### ⭐ 权益的时间怎么算（重点）

**办了卡但顾客还没来用 = 「未激活」**，天数不会白流：

```
10/1  顾客买了周卡，但没来          → 未激活（7 天先存着）
10/5  顾客第一次来，用卡开台        → 激活！10/5 起算，有效期 10/5 – 10/11
10/12 顾客续一张                    → 新一期 10/12 – 10/18（紧接着上一期）
```

- **未激活的卡永久有效**，顾客什么时候来都能用
- **未激活时又买一张，天数累加**（两张周卡 = 14 天）
- **续卡不浪费**：新一期紧接原到期日的次日，一天不重叠

界面上会明确标出状态：

| 状态 | 显示 |
|---|---|
| 未激活 | 🎫 周卡 · 未激活（待生效 7 天） |
| 生效中 | 🎫 周卡 · 10月5日 — 10月11日（剩 3 天） |
| 已过期 | 🎫 周卡 · 已过期（10月11日） |

### 7. 取消开台（顾客开台后没消费就走了）

```
点该桌进详情 → 最下面「取消开台」→ 填原因
             → 点一次变「再点一次确认取消」→ 再点一次生效
```

- 用于：顾客开台后马上离开、套餐选错想撤销、临时不玩了
- **不产生任何金额**，桌位立即释放
- **已经结过账的台不适用**，要去「收入 → 订单」用整单作废
- 原因会记进操作日志，方便日后查

## 三、收费规则（系统自动算）

### 超时：系统只计时，不自动收费

**超时收多少钱，由店里自己定。系统不会自动加钱。**

超时后系统会告诉你两件事，收不收、收多少你说了算：

```
① 到点前 15 分钟：看板卡片变黄色（即将到时）
② 超时后：卡片变红色，并显示超了多久

结账时页面上会写「已超时 30 分钟」，
需要加收的话，把「实收金额」改成套餐价 + 你要收的超时费即可。
```

**举例**：单人1小时 ¥12.80，实际玩了 1 小时 30 分

| | |
|---|---|
| 系统算的应收 | ¥12.80（不含超时费） |
| 你想收 ¥20 | 把实收改成 `20` |
| 结果 | 订单实收 ¥20，多收的 ¥7.20 记成「人工调整」，账目清楚 |

> 限板套餐、日卡、周卡核销本来就不限时，也就无所谓超时。

### 打折日

**每月 8 / 18 / 28 日**，套餐和加购**自动 8 折**。

- ✅ 参与：限时套餐、限板套餐、日卡、加购项
- ❌ 不参与：周卡

### 到时提醒

到期前 **15 分钟**，看板卡片变**黄色**；超时后变**红色**、显示超时时长。

## 四、查看收入

底部「收入」：

| 标签 | 内容 |
|---|---|
| **汇总** | 今日营业额、单数、办卡数、各支付方式金额 |
| **流水** | 每一笔收款的详细记录（含退款、作废） |
| **订单** | 按订单查看明细，可作废 |

### 对账

系统自动核对「流水总额 = 订单总额」，首页会显示是否平衡。

**如果收到对账异常提醒，先别继续收款，联系管理员。**

## 六、常见问题

**Q：顾客的套餐选错了，已经开台了怎么办？**
A：详情页「换套餐」直接改，系统按新套餐重新计算。

**Q：结账时金额填错了？**
A：已结账的订单不能改，只能在「收入 → 订单」里**作废**后重新开台。

**Q：两个顾客同名怎么办？**
A：系统显示「昵称 · 手机尾号」+ 会员编号 + 到店次数。建议收银时多问一句尾号。

**Q：桌位显示「维护中」怎么恢复？**
A：「设置 → 桌位」点该桌，确认恢复。

**Q：忘了管理员密码？**
A：联系技术人员在服务器上重置。

**Q：微信里打开打不开？**
A：微信会拦截。用**手机自带浏览器**（Safari / Chrome / 小米浏览器）打开。

### 手动备份

```bash
/opt/pindou-backup/backup.sh
```

### 从备份恢复

```bash
gunzip -c /opt/pindou-backup/pindou-2026-10-11_173139.sql.gz | sudo -u postgres psql pindou
```

> ⚠️ 恢复会覆盖当前数据，操作前先做一次手动备份。

### 更新代码后重启

```bash
cd /opt/pindou
npm run build
pm2 restart pindou-api
```
